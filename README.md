# Taste of Africa

A multi-page website celebrating African cuisine, built with HTML5, CSS and vanilla JavaScript. By **Divine Mutesi**.

**Live site:** https://github.com/divine150-coder/taste_of_africa_website_project

## Pages
- **Home:** hero with intro video, featured dishes, regions and food trends
- **Recipes:** filter by region and save favorites
- **Recipe pages:** Jollof Rice, Tagine, Injera, Bunny Chow, Isombe
- **Region pages:** West Africa, North Africa, East Africa
- **About:** mission, history and map
- **Contact:** form with validation

## Features
- Recipe filter by region
- Favorites saved in localStorage
- Ingredient scaler on recipe pages
- Dark / light mode
- Contact form validation with a personalised thank-you message
- Newsletter signup in the footer

## Run locally
1. Clone the repository:
   ```bash
   git clone 'https://github.com/divine150-coder/taste_of_africa_website_project'
   cd taste_of_africa_website_project
   ```
2. Open the folder in VS Code.
3. Install the **Live Server** extension.
4. Right-click `index.html` and choose **Open with Live Server**. The site opens at `http://127.0.0.1:5500`.

Don't double-click `index.html`. If the page is opened directly as a file, YouTube blocks the embedded videos.

No Git? On the GitHub page click **Code**, then **Download ZIP**, unzip it, and continue from step 2.
